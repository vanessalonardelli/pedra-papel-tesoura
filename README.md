# Pedra, Papel e Tesoura

Jogo feito com HTML, CSS e JavaScript, sem bibliotecas.

## Como jogar

Clique em Pedra, Papel ou Tesoura. O computador escolhe a jogada dele ao mesmo tempo.

- Pedra vence tesoura
- Tesoura vence papel
- Papel vence pedra

Quem fizer 3 pontos primeiro vence a partida. Para começar outra partida, clique em "Jogar de novo".
